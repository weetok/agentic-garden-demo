## Rules

1. Exactly the five sections, in the fixed order; the generator never adds,
   removes, or renames sections.
2. This week, Outlook, Advice, and Why are all generated from the same
   derived_data instance the dashboard shows — no hand-written facts anywhere
   in the briefing. This week and Outlook are grounded in derived_data's
   series/metrics and `outlook` fields respectively; Advice and Why use
   identical actions and identical trace order.
3. The Numbers table contains exactly the five headline metrics, same values
   as derived_data, units written out in the table header.
4. No content above the H1 title; footer line "Generated by the Agentic Garden
   pipeline on {generated_at}" is the last line, where `generated_at` is format as DD-MM-YYYY.
5. Plain markdown only: headings, bullets, one table. No HTML, no images;
   the file must read cleanly in the GitHub repo view as well as the dashboard.

## Example

```md
# Weekly briefing — week 31, 2026

## This week <!-- 3–5 sentences, past period: what happened -->

## Outlook <!-- 2–4 sentences, forecast period -->

## Advice <!-- the headline advice verbatim from derived data, then one bullet per bed action -->

## Why <!-- the why-trace, one bullet per entry, same order -->

## Numbers <!-- small table: the five headline metrics -->

Generated by the Agentic Garden pipeline on 01-08-2026
```
